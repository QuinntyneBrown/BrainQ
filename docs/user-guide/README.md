## Conventions used in this guide

- **Buttons and labels** are written like `Save to brain`.
- **Screens** are written in title case: Today, Brain, Search, Detail.
- **Entity types** are capitalized: Note, Idea, Person, Project, Commitment.
- Where a control behaves differently across viewports, the guide calls out **xs** (≈375px wide phone), **md** (≈768px wide tablet), and **xl** (≥1280px wide desktop).
